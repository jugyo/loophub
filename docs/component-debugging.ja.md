# コンポーネントデバッグの命名規約

`ComponentDebugToggle` を有効にすると、`data-debug-component` 属性を持つ
要素がオーバーレイで可視化される。この属性は、画面のどの機能領域を調査して
いるかを人とエージェントが共有するための名前であり、DOM の全要素を表示する
ためのものではない。

## 付与する粒度

次のいずれかに当てはまる、画面上で領域を持つ要素に付与する。

- ルートが直接描画するページ
- 見出しや枠などで区切られた主要な機能セクション
- 単独で開閉または操作できるダイアログ、ポップオーバー、パネル
- リスト内で一つの対象を表す行やカード
- 複数ページで再利用され、独立した役割を持つ UI

次の要素には原則として付与しない。

- アイコン、バッジ、ボタン、入力欄などの低レベル UI 部品
- レイアウト調整だけを目的とするラッパー
- 見出し、説明文、区切り線などの装飾的な子要素
- 属性を持つ親と同じ役割しか表さない内部要素
- `Provider` やデータ取得用コンポーネントなど、画面上の領域を持たないもの

## 命名

- React コンポーネント名と同じ `PascalCase` を使う。
- ローカル関数コンポーネントも、役割を表す関数名をそのまま使う。
- JSX 内に直接書かれた意味領域は、既存の語彙に合わせた
  `PascalCase` 名を使う（例: `PullSidebar`）。
- ルート名や表示文言、データ ID、連番を名前に含めない。名前は表示中のデータ
  が変わっても安定させる。

```tsx
<section data-debug-component="ReviewList">...</section>
```

## 重複名

リストの行、カード、同じ種類のセクションなど、同一コンポーネントの複数
インスタンスには同じ名前を使う。オーバーレイは DOM 上の各要素を別々に囲むため、
連番やデータ ID を付けて一意にする必要はない。

異なる役割のコンポーネントが偶然同じ名前になる場合は、より具体的な役割名へ
変更する。ページ名を接頭辞として機械的に付けるのではなく、単独で意味が通る
名前を優先する。

## 新しい画面を追加するとき

1. ページの最上位要素へページコンポーネント名を付ける。
2. 見出しや枠で識別できる主要セクション、独立したダイアログ、繰り返し行を
   上記の粒度で確認する。
3. デバッグモードを有効にし、対象の名前がオーバーレイに表示されることを確認する。
4. 同じ役割に複数の名前を付けていないか、低レベル部品まで細分化していないかを
   確認する。

## 現在の棚卸し範囲

次の画面と共通 UI を上記の基準で確認している。ルートコンポーネントが別の
ページコンポーネントを直接返す場合は、実際に領域を描画する側へ名前を付ける。

| 画面 | 確認した主な領域 |
| --- | --- |
| アプリ共通 | レイアウト、トップバー、リポジトリバー、ステータスバー、ルート内容、通知、トースト、リポジトリ切り替え、検索、各種ダイアログ |
| ホーム、Archived | ページ、リポジトリ一覧と行、最近の Issue、リポジトリ追加 |
| リポジトリダッシュボード、Issue 一覧 | ページ、検索、フィルタ、ワークスペース別セクション、Issue 行 |
| Issue 詳細 | ヘッダ、関連 PR、Agents、コメント一覧、コメント、投稿フォーム |
| PR 詳細 | ヘッダ、コミット、ファイル差分、レビュー、コメント、Agents、Workflow run、worktree、GitHub PR 状態、作業時間 |
| リポジトリ設定、Scheduled tasks | 各設定セクション、タスクカード、編集フォーム、実行履歴、確認ダイアログ |
| Settings、Workflows | Coding agent、コスト上限、ワークフロー一覧、カード、フォーム、システムプロンプト、確認ダイアログ |
| Agents | ページ、Herdr セッション、PR worktree、エージェントツリーと行 |
| Stats、DB Stats、Agent sessions | ページ、統計リンク、DB／テーブル／リポジトリ統計、期間操作、概要、グラフ、比較、セッション表と行 |
| Inbox | ページ、メッセージ表、行、展開内容 |
| 内部／遷移画面 | UI catalog、参照解決、セッション遷移 |

## 検証証跡

PR 詳細画面でデバッグモードを有効にし、ヘッダ、コミット、差分、レビュー、
コメント、サイドバーの各領域名がオーバーレイに表示されることを確認している。
